# NEXUS — Cyborg-Themed Landing Page

A responsive futuristic landing page built with plain HTML, CSS, and JavaScript for Task 1.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive cyberpunk styling, cyborg illustration, effects, and animations
- `script.js` — mobile menu, scroll reveal, active navigation, stat counters, and demo form feedback

## Run locally
1. Extract the ZIP file.
2. Open the `nexus_cyborg_landing_page` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and click **Go Live**.
4. Test the navigation, buttons, responsive layout, scrolling animations, and contact form.

## Notes
- No build step or npm packages are required.
- Google Fonts are loaded online. The page still works with fallback fonts if offline.
- The contact form is a front-end demo. It validates fields and displays a confirmation locally; it does not send or store messages.
- Replace the demo contact form behavior with a backend endpoint if the task specifically requires real message delivery.
